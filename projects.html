Threat Intelligence // Python

ThreatView — Intelligence Dashboard

Pulls live threat data from multiple security feeds and turns raw noise into clear, actionable insights — built for teams who need to react fast without a massive budget.

The Problem It Solves

Small businesses are constant targets for cyberattacks but enterprise threat intelligence platforms cost a fortune. ThreatView fills that gap — it pulls data from open-source feeds like AlienVault OTX and PhishTank, normalizes it, and displays it in a way that even a non-security IT manager can understand and act on immediately.

How It Works
  • ETL pipeline collects data from multiple threat APIs
  • Normalizes different formats into one unified threat model
  • Live charts — attack maps, malware trends, IoC lists
  • Search any IP or domain against threat feeds instantly
  • Smart alerts — e.g. notify if your industry is being targeted
What I Built
  • Python + FastAPI backend ingestion engine
  • Celery scheduler — auto-refreshes threat data every hour
  • Redis for caching and job queue management
  • PDF report generator for weekly threat summaries
  • Role-based access — free vs pro tier logic

Web Security // Automation

VulnScan Lite — Web Vulnerability Scanner

Paste any URL, get an instant security health report. Scans for XSS, SQLi, missing headers, SSL issues and more — passive, safe, and legal analysis only.

The Problem It Solves

Most website owners have no idea they are vulnerable until they get hacked. VulnScan Lite lets anyone enter a URL and instantly see a security score — graded like a report card — with plain-English explanations of every issue and exactly how to fix it. No aggressive attacks, completely passive analysis.

What It Checks
  • HTTP security headers — CSP, X-Frame-Options, HSTS
  • SSL/TLS certificate validity and cipher strength
  • CMS detection — outdated WordPress, Drupal, etc.
  • Exposed server info and common misconfigurations
  • Scoring — each check adds or deducts points (0–100)
Technical Highlights
  • Async scan queue via Celery + Redis — no page freezes
  • React frontend polls scan status every 2 seconds live
  • Gauge chart showing real-time security score
  • PDF report with full remediation tips per finding
  • Scan history — track your security score over time
