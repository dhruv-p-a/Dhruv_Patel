Android Pen-Testing App

Vulnerability Assessment Toolkit

Description

This project is a comprehensive mobile application designed for security professionals and ethical hackers. Built entirely in Kotlin, it allows users to perform various vulnerability assessments directly from their Android device.

It includes modules for network scanning, sniffing, and basic exploit testing within controlled environments.

Technologies

  • • Kotlin
  • • Android SDK
  • • Nmap Integration
